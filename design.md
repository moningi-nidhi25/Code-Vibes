## Brand & Style

This design system expresses a forward-looking developer ecosystem driven by velocity, architectural precision, and electric craft. Designed for modern engineering platforms, telemetry command centers, and high-throughput technical dashboards, it merges **Precision Engineering** with **Luminous Glassmorphism**.

The visual language pairs high-clarity light foundations and multi-layered translucent glass panels with the radiant tri-color energy of the brand spectrum: **Electric Cyan**, **Vivid Cobalt Blue**, and **Electric Violet**. Frosted glass planes float over ambient multi-stop radiant gradients, creating multi-dimensional hierarchy without sacrificing technical legibility.

Key aesthetic tenets:
- **Luminous Glassmorphism:** Translucent glass plates featuring multi-tier backdrop blurs (`12px` to `40px`), saturation boosts (`140%` to `180%`), and micro-fine specular border highlights catch light and visually separate dense data streams.
- **Ambient Spectral Foundations:** Deep-field radial and conic multi-stop gradients infuse canvases with low-intensity energy behind frosted viewports.
- **Bento Structural Architecture:** Micro-bordered, frosted glass modules compartmentalize complex data streams into legible, modular viewports.
- **Engineered Legibility & Strict Contrast:** High-precision monospace metrics and geometric headings pair with strict WCAG AA / APCA compliant typography layered over translucent containers.

## Colors

The color palette centers on high-voltage spectral chromatic tokens anchored over a crystalline, high-contrast surface hierarchy. Translucent frosted layers allow subtle chromatic light from ambient canvases to filter through while preserving pristine text contrast.

### Color Hierarchy & Roles
- **Primary (`#2979FF`):** Vivid Cobalt Blue. The anchor for primary user flows, focused glass card borders, structural buttons, and active tabs.
- **Secondary (`#00E5FF`):** Electric Cyan. Real-time telemetry, WebSocket ping indicators, code accents, and radiant gradient heads.
- **Tertiary (`#B324E5`):** Electric Violet. Escalated administrative states, premium badges, and gradient terminals.
- **Neutral (`#0B1120`):** Cyber Slate-Black. High-density contrast text for primary syntax and layout headers.

### Glass Translucency & Specular Tints
- **Glass Subtle (`rgba(255, 255, 255, 0.70)`):** Base backdrop layer used for tertiary sidebars, background card grids, and inactive trays. Paired with `backdrop-filter: blur(12px) saturate(140%)`.
- **Glass Base (`rgba(255, 255, 255, 0.80)`):** Default container tier for bento cards, standard data tables, and forms. Paired with `backdrop-filter: blur(16px) saturate(160%)`.
- **Glass Elevated (`rgba(255, 255, 255, 0.90)`):** Floating toolbars, dropdowns, popovers, and stacked overlay cards. Paired with `backdrop-filter: blur(24px) saturate(180%)`.

### Luminous Strokes & Edge Highlights
- **Specular Highlight Stroke (`rgba(255, 255, 255, 0.60)`):** Top and left directional border highlights that simulate overhead studio lighting.
- **Ambient Edge Stroke (`rgba(255, 255, 255, 0.20)`):** Bottom and right rim lighting for glass surfaces.
- **Structural Stroke (`rgba(194, 198, 215, 0.35)`):** Uniform 1px stroke applied to components resting against low-saturation backgrounds to maintain crisp geometric boundaries.

### Multi-Stop Ambient Gradients
- **Hero Mesh Canvas:** `radial-gradient(at 0% 0%, rgba(0, 229, 255, 0.15) 0px, transparent 50%), radial-gradient(at 100% 0%, rgba(179, 36, 229, 0.12) 0px, transparent 50%), radial-gradient(at 50% 100%, rgba(41, 121, 255, 0.10) 0px, transparent 60%)`.
- **Core Action Linear:** `linear-gradient(135deg, #00E5FF 0%, #2979FF 50%, #B324E5 100%)`.

## Typography

Typography balances cybernetic precision with fatigue-free readability over translucent surfaces:

- **Display & Headlines (`Space Grotesk`):** Structural, geometric, and assertive. Calibrated with negative letter tracking to build condensed, commanding titles.
- **Body & Controls (`Inter`):** Systematic workhorse providing neutral, razor-sharp forms across technical prose, nested lists, and UI controls.
- **Syntax, Telemetry & Keycaps (`JetBrains Mono`):** Dedicated to code syntax, latency gauges, memory counters, API endpoints, and keyboard shortcut chips.

### Legibility & Contrast Rules on Frosted Surfaces
- Never place text lighter than `#151B2B` on frosted surfaces with opacity below `90%` unless an inner solid text-scrim is applied.
- All body typography on glass containers must hit an APCA Lc rating of 75+ or WCAG AA minimum contrast of 4.5:1 against the blended glass background.
- For secondary copy (`#475569`) on `70%` opacity frosted surfaces, the container must employ minimum `backdrop-filter: blur(16px)` to avoid text bleeding into underlying gradient meshes.

## Layout & Spacing

Layouts adhere to an architectural Bento grid structure mapped across flexible 12-column systems and responsive administrative viewports.

### Grid Rhythm & Viewports
- **Public Developer Portal:** 12-column responsive grid with a maximum content container of `1280px`. Outer margins are set to `2rem` (`1rem` on mobile) with column gutters of `1.5rem` (`1rem` on tablet/mobile).
- **Dense Control Console:** Full-width layout flanked by a fixed frosted glass sidebar navigation rail (`240px`, collapsible to `64px`) and an internal `1rem` modular bento separation.
- **Rhythm Base:** Rigid 4px/8px incremental rhythm governing all component padding, gaps, and outer bounds.

### Responsive Behavior
- **Desktop (1024px+):** Full multi-column Bento grids displaying parallel translucent panels.
- **Tablet (768px - 1023px):** Columns collapse into a 2-column stacked arrangement. Backdrop blur defaults to `backdrop-blur-md` (`12px`) for GPU efficiency.
- **Mobile (< 768px):** Single-column vertical stack. Outer margins clamp to `1rem`. Translucent panels step up to `90%` opacity to protect text legibility over condensed ambient backdrops.

## Elevation & Depth

Visual depth is achieved through optical glass stratification, directional specular light borders, and ambient colored glows rather than heavy, opaque dropshadows.

### Frosted Glass Surface Levels
- **Glass Tier 1 (`backdrop-blur-md` / 12px):** `rgba(255, 255, 255, 0.70)` fill. Used for base canvas trays, segmented controls, and secondary bento tiles.
- **Glass Tier 2 (`backdrop-blur-lg` / 16px):** `rgba(255, 255, 255, 0.80)` fill. Standard container tier for primary bento cards, data tables, and code consoles.
- **Glass Tier 3 (`backdrop-blur-xl` / 24px):** `rgba(255, 255, 255, 0.90)` fill. Used for floating command palettes (⌘K), contextual flyouts, and fixed header navigation.
- **Glass Tier 4 (`backdrop-blur-2xl` / 40px):** `rgba(255, 255, 255, 0.92)` fill. High-priority modals, critical confirmations, and floating inspection drawers.

### Luminous Borders & Highlight Directionality
Every glass panel features a 1px composite outline:
- **Gradient Luminous Border:** Applied via `border-image` or layered inset boxes:
  - Top & Left Edge: `rgba(255, 255, 255, 0.60)` creating a crisp refraction highlight.
  - Bottom & Right Edge: `rgba(255, 255, 255, 0.20)` blending into the shadow plane.
- **Outline-Variant Mode:** When rendered on flat light surfaces, fallback to `rgba(194, 198, 215, 0.35)`.

### Soft Diffuse Tinted Glow Shadows
Shadows leverage diffuse color bleeding rather than dark alpha masks:
- **Default Card Shadow:** `0 10px 30px -10px rgba(11, 17, 32, 0.05), 0 1px 3px 0 rgba(11, 17, 32, 0.02)`.
- **Cobalt Glow (Interactive/Raised):** `0 14px 32px -4px rgba(41, 121, 255, 0.22), 0 2px 8px -2px rgba(41, 121, 255, 0.12)`.
- **Cyan Glow (Telemetry/Active):** `0 12px 28px -4px rgba(0, 229, 255, 0.28), 0 0 12px 0 rgba(0, 229, 255, 0.15)`.
- **Violet Glow (Elevated Permission):** `0 12px 28px -4px rgba(179, 36, 229, 0.25), 0 0 10px 0 rgba(179, 36, 229, 0.12)`.

### Glass Stacking Rules
When nesting frosted glass elements (e.g., a card inside an existing frosted layout panel):
1. **Never stack identical opacities:** A child glass component must always have an opacity tier at least 10% higher than its parent container (e.g., a `80%` card rests inside a `70%` section, a `90%` action chip rests inside an `80%` card).
2. **Backdrop blur accumulation:** Child elements inside an already blurred parent must reduce their own blur by one tier or rely strictly on solid surface tinting to avoid compositing bottlenecks and optical mud.

## Shapes

The geometry uses a balanced modern radius scale to complement light refraction along rounded bevels:

- **Inputs, Buttons, and Micro Controls:** `0.5rem` (`rounded-md`). Provides clean tactile targets with crisp border illumination.
- **Bento Containers, Code Blocks, and Modals:** `1rem` (`rounded-lg`). Broad corner curves allow luminous glass edge highlights to bend smoothly without visual clipping.
- **Pills, Status Badges, and Terminal Chips:** `9999px` (`rounded-full`). Instantly distinguishes interactive or real-time state flags from structural layout modules.

## Components

### Buttons
- **Gradient Primary Button:** Fill consists of `linear-gradient(135deg, #00E5FF 0%, #2979FF 50%, #B324E5 100%)` with white text (`#FFFFFF`) at weight 600. Features a 1px border `rgba(255, 255, 255, 0.40)`. On hover: `translateY(-1px)`, with glowing shadow `0 6px 20px rgba(41, 121, 255, 0.35)`. On active: `translateY(0)` and scale `0.99`.
- **Frosted Glass Button:** Fill is `rgba(255, 255, 255, 0.75)` with `backdrop-filter: blur(12px)`, bordered with `rgba(255, 255, 255, 0.60)` on the top edge and `rgba(194, 198, 215, 0.40)` around. On hover: fill shifts to `rgba(255, 255, 255, 0.90)`, border shifts to `rgba(41, 121, 255, 0.50)`, accompanied by diffuse Cobalt Glow.

### Chips & Badges
- **Frosted Telemetry Chip:** Fully rounded pill with `rgba(255, 255, 255, 0.70)` fill, `12px` blur, and a 1px `rgba(255, 255, 255, 0.50)` stroke.
- **Live Status Badges:**
  - *Active / Online:* Cyan ping indicator (`#00E5FF`) with animated ripple on a `rgba(0, 229, 255, 0.10)` glass pill.
  - *Processing:* Cobalt pulse (`#2979FF`) over `rgba(41, 121, 255, 0.10)`.
  - *Restricted / Critical:* Violet badge (`#B324E5`) using `JetBrains Mono` text over `rgba(179, 36, 229, 0.10)`.

### Bento Cards & Frosted Containers
- **Standard Bento Card:** Composed of `rgba(255, 255, 255, 0.80)` fill, `16px` backdrop-blur, and dual-layer border highlight (top: `rgba(255, 255, 255, 0.60)`, sides/bottom: `rgba(194, 198, 215, 0.30)`).
- **Card Interactive Hover:** On hover, the container performs `translateY(-2px)`, the background shifts to `rgba(255, 255, 255, 0.90)`, and a directional Cobalt ambient glow activates (`0 14px 32px -4px rgba(41, 121, 255, 0.20)`).
- **Card Active State:** Scales to `0.995` with inset highlight stroke `rgba(41, 121, 255, 0.40)`.

### Input Fields & Terminal Search (⌘K)
- **Glass Text Input:** `rgba(255, 255, 255, 0.85)` background, `backdrop-filter: blur(12px)`, and a 1px `rgba(194, 198, 215, 0.50)` border.
- **Input Focus State:** Surface transitions to `rgba(255, 255, 255, 0.98)` with a 1px solid `#2979FF` border and an outer focus ring: `0 0 0 3px rgba(41, 121, 255, 0.20)`.
- **Floating Command Bar (⌘K):** High-tier glass modal (`backdrop-blur-xl`, `rgba(255, 255, 255, 0.92)`), framed with specular white rim highlights and accompanied by `JetBrains Mono` keycap pills.

### Checkboxes & Radio Buttons
- **Checkboxes:** Unchecked state uses a frosted square (`rgba(255, 255, 255, 0.80)`) with 1px `rgba(114, 119, 134, 0.40)` border. When checked, transitions to a solid `#2979FF` fill with a crisp `#FFFFFF` checkmark and a subtle cyan-tinted glow (`0 0 8px rgba(0, 229, 255, 0.40)`).
- **Radio Buttons:** Concentric ring design matching the checkbox glass base, transitioning on selection to a `#2979FF` ring encircling a solid primary dot.

### Lists & Code Viewports
- **Frosted Syntax Viewport:** Container with `rgba(255, 255, 255, 0.85)` fill, `backdrop-filter: blur(16px)`, structural top header bar separating code actions from body, and JetBrains Mono syntax rows highlighted with accessible spectral tokens.
- **Glass Data Table Rows:** Default row fill `transparent`; on hover, rows transition smoothly to `rgba(41, 121, 255, 0.05)` with a left edge highlight in `#00E5FF`.
