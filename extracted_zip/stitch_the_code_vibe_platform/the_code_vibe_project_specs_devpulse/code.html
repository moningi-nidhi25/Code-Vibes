Local Environment & First Run

Rust 1.78+ · Clang/LLVM 16+ · Docker 24+
terminal ~ rust-agent
# 1. Clone & prepare submodules (libbpf)
$ git clone https://github.com/thecodevibe/devpulse.git
$ cd devpulse && git submodule update --init --recursive
# 2. Build kernel probes & agent
$ cargo build --release -p devpulse-collector
# 3. Test probe attachments (requires sudo for eBPF)
$ sudo ./target/release/devpulse-collector --dry-run
terminal ~ docker-stack
# 1. Spin up Kafka, ClickHouse & Mock Ingest
$ docker compose -f deploy/local-testbed.yml up -d
# 2. Launch real-time React dashboard
$ cd web && pnpm install && pnpm dev
# 3. View telemetry live at http://localhost:5173
✔ [Ready] Connected to WebGL canvas telemetry socket
